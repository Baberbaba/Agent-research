This project is an AI-powered research assistant built using LangChain and LangGraph. It is designed to answer user queries by using tools such as web search and Wikipedia-style information retrieval, and it can also save results to a local file for later use. The system uses a tool-calling agent powered by GPT-4o-mini, which allows the model to decide when and how to use available tools to generate better and more accurate responses. The agent runs in a reasoning loop where it analyzes the query, selects appropriate tools, processes their outputs, and then returns a final summarized answer.
The project is built using Python and depends on libraries such as LangChain, LangGraph, Pydantic, and DuckDuckGo Search. The OpenAI API key is required to run the project, which should be stored in a .env file and not uploaded to GitHub for security reasons. The code is organized into a main file that handles the agent logic and a separate tools file that defines the search, Wikipedia, and save functions used by the agent.
To run the project, install the required dependencies, set up the environment variables, and execute the main.py file. Once running, the user can input a question, and the agent will automatically decide which tools to use and return a well-structured research-based answer.
